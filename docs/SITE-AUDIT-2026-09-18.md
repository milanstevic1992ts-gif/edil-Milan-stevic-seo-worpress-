## Regola operativa
Prima di consolidare, redirezionare, mettere noindex o eliminare una pagina:
1. controllare query e landing page in Search Console;
2. controllare link interni ed esterni;
3. verificare canonical e stato di indicizzazione;
4. stabilire l'intento principale della pagina;
5. scegliere se differenziare, consolidare con 301, mantenere oppure noindex.

EMS Local SEO deve proporre queste decisioni, non applicarle automaticamente.
