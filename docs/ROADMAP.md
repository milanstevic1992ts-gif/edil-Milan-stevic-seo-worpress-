## Principi
1. Nessun keyword stuffing.
2. Nessuna promessa di ranking.
3. Niente markup non supportato solo per fare schema.
4. Contenuti e schema devono descrivere informazioni reali visibili sul sito.
5. Un solo proprietario per title/meta/canonical/robots: EMS oppure un plugin SEO esterno, mai entrambi.
